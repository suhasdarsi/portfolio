Most security work ultimately protects data. These tools work on the data itself, wherever it sits and wherever it moves.

## How it breaks down

- **Data security posture (DSPM)** scans cloud storage, databases and SaaS for sensitive data, shows who can reach it, and points out what is overexposed. It answers “where is our customer data?”
- **Data loss prevention** follows data as it moves through email, SaaS, endpoints and, more and more, AI tools, and blocks or warns when sensitive data is about to leave.
- **Encryption** makes data useless without the key, from a single file to a whole disk to individual fields in a database.
- **Backup and recovery** is the last line: immutable copies that ransomware can’t touch, and fast restores.

## Where to start

Make sure backups exist and that you can actually restore from them. Then find where sensitive data lives before you try to control how it moves. DLP works much better once you know what you are protecting.
