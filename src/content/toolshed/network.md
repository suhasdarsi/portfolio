The old model of a trusted inside and an untrusted outside has mostly gone. Network security tools now follow users and workloads wherever they are.

## How it breaks down

- **SASE and SSE** deliver network security from the cloud: secure web access, private app access and data controls for users anywhere.
- **Zero-trust access and mesh VPNs** connect people and machines directly to the resources they are allowed to reach, without exposing a VPN concentrator.
- **Firewalls and network policy** decide what traffic is allowed, from the network edge down to a single app on a Mac or a pod in Kubernetes.
- **DNS filtering** blocks malicious and unwanted domains at the lookup. It is cheap, and it works everywhere.
- **Edge and web application firewalls** protect public sites and APIs from attacks and bots.
- **Traffic analysis** captures packets when you need to see exactly what is on the wire.

## Where to start

DNS filtering and a zero-trust access tool replace most of what a small team needs from a VPN. SASE platforms make sense when you need web filtering, data controls and private access in one place for a large workforce.
