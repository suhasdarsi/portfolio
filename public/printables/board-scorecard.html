Board toolkit · AI agent security

Five questions, every quarter

Write down what you were told, then rate it. A strong answer has a number, a date and an owner. A weak one has reassurance.

Strong answers
0 / 5
01

How many agents run here, and who owns each?

Ask for
The count found running, with an owner for each entry.
Strong answer
An inventory built from real devices and networks, dated and owned.
Red flag
A survey, a policy, or a list of approved tools.
02

What can each agent reach and do?

Ask for
Access for the ten most powerful agents, and why each needs it.
Strong answer
A one-line written scope for each, reviewed this quarter.
Red flag
“It uses the employee’s login.”
03

What happens automatically in the first ten minutes?

Ask for
The list of pre-approved actions: lock, end session, isolate.
Strong answer
A short written list, each action with limits and an approver.
Red flag
“The analyst escalates,” with no list.
04

Can we stop one agent without stopping the business?

Ask for
Time to cut off a single agent, and who is allowed to do it.
Strong answer
A named role, a tested procedure, and a measured time.
Red flag
“We would disable the user.”
05

When did we last practise this, and what broke?

Ask for
The last exercise, and the one thing that failed.
Strong answer
A recent drill, a real failure, and what changed after.
Red flag
“No issues found,” or no exercise at all.
Rate each answer: Strong = number, date, owner. Partial = one of those. Weak = reassurance only. Track the trend, not one quarter. suhasdarsi.com/notes/questions-boards-should-ask-ai-agent-security
